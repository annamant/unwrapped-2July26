## Voice on LinkedIn

- Same brand bible: editorial, sparse, concrete — not SaaS pitch
- Lead with the locked one-liner; never “for shoppers / for businesses” as the definition
- CTAs can still point both ways: shopunwrapped.com · shopunwrapped.com/business-apply
- Do not invent metrics, partner names, or live drop counts

## Login & posting

Operate via the human’s browser session. Never store passwords.

1. Open LinkedIn. If login / 2FA → pause and ask them to sign in.
2. Post **as the Company Page** (switch identity), not the personal profile, unless they ask otherwise.
3. Default: draft. Publish only when they say post / publish.
4. Record posts under `marketing/linkedin/` when that folder exists.

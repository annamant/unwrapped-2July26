## How to use this list

1. **Next shoot** = first `queued` row in Phase 1 (unless Anna picks another).  
2. When photos land → status `photos_in` + start draft folder `YYYY-MM-DD-[street-slug]/`.  
3. When posted → `posted` + add calendar row + Instagram URL.  
4. **One episode = one named strip.** If a road is huge (Kingsland, Holloway, King’s Road), note the stretch in `notes.md`.  
5. Do **not** invent streets for product claims. This list is editorial / discovery only.  
6. Anna can reorder, skip, or insert streets — update this file when she does.
